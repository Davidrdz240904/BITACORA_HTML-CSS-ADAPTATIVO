JavaScript

JavaScript

JavaScript (JS) es un lenguaje de programación fundamental para la web, interpretado y multipropósito, que permite crear contenido dinámico y experiencias interactivas en sitios web, así como aplicaciones del lado del servidor (Node.js), de escritorio y móviles. Su objetivo principal es añadir interactividad a las páginas web, funcionando en el navegador del usuario para modificar la interfaz y manejar datos.

Como funciona?

Lenguaje de la web

Es un lenguaje de programación de scripts que se ejecuta directamente en los navegadores web, que interpretan su código para realizar acciones específicas.

interactividad

Permite crear elementos dinámicos como menús desplegables, formularios interactivos, animaciones, y la actualización de contenido sin necesidad de recargar la página.

Versatilidad

Aunque nació para el navegador, JavaScript se expande a otras áreas como el backend con Node.js, aplicaciones de escritorio y desarrollo móvil.

funciones

funciones

Una función en JavaScript es similar a un procedimiento — un conjunto de instrucciones que realiza una tarea o calcula un valor, pero para que un procedimiento califique como función, debe tomar alguna entrada y devolver una salida donde hay alguna relación obvia entre la entrada y la salida. Para usar una función, debes definirla en algún lugar del ámbito desde el que deseas llamarla.

funciones RETURN

funciones que retornan valor

En JavaScript, las funciones que retornan valores utilizan la sentencia return para finalizar la ejecución de la función y devolver un valor específico. Este valor de retorno puede ser cualquier tipo de dato, como un número, una cadena, un objeto o incluso otra función, y puede ser almacenado en una variable o utilizado directamente en otra parte del código

Llamada a una funcion

Llamada a una funcion

Para llamar una función en JavaScript, se escribe el nombre de la función seguido de paréntesis (). Si la función espera argumentos, se pasan dentro de los paréntesis separados por comas. También puedes llamar a funciones usando otros métodos como call() para especificar un valor para this o usando atributos de evento HTML como onclick.

Imprimir en consola

Imprimir en consola

Para imprimir el resultado de una función JavaScript en la consola, usa console.log() y pasa la llamada a la función dentro de los paréntesis. Esto imprimirá el valor que la función retorna directamente en la consola del navegador o del entorno de ejecución.

GetElementbyid

GetElementbyid

document.getElementById() es un método de JavaScript que busca un elemento HTML específico utilizando su atributo id y lo devuelve como un objeto. Es la forma más rápida y eficiente de acceder a un único elemento, siempre y cuando este tenga un id único en el documento. Una vez obtenido, se puede usar para manipular las propiedades del elemento, como su contenido, estilos, etc.

addeventlistener

addeventlistener

es un método de JavaScript que adjunta una función para escuchar eventos en un elemento de un objeto, como un botón, el documento o la ventana. Permite ejecutar código de forma dinámica en respuesta a interacciones del usuario, como clics o movimientos del ratón, sin sobrescribir los manejadores de eventos existentes y puede tener múltiples manejadores para el mismo evento en un solo elemento
